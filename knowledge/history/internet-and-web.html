The Internet & the World Wide Web

The final leap: connecting the world's computers into one network. This is the story of packet switching, the protocols that let any machine talk to any other, and the web that made it usable by everyone.

J.C.R. Licklider — The Vision

J.C.R. Licklider (1915–1990), a psychologist and computer scientist, wrote about a "Intergalactic Computer Network" in the early 1960s.

  • Foresaw interactive computing and globally interconnected computers sharing data and programs.
  • As a director at ARPA, he funded the research that led to time-sharing and eventually the ARPANET.

Baran & Davies — Packet Switching

The key technical idea was packet switching — breaking data into small packets routed independently across a network.

  • Paul Baran (RAND, USA) proposed a distributed, survivable network that could keep working even if parts were destroyed.
  • Donald Davies (NPL, UK) independently developed the same concept and coined the term "packet."
  • Packet switching replaced fragile, dedicated circuit connections with a resilient, shared network.

ARPANET — The First Network

The ARPANET went live in 1969, funded by the U.S. Department of Defense's ARPA.

  • The first message was sent between UCLA and Stanford; the system crashed after transmitting "LO" of "LOGIN."
  • Leonard Kleinrock contributed foundational queuing/network theory and hosted the first node.
  • ARPANET proved that packet-switched networking worked at scale and became the technical ancestor of the internet.

Cerf & Kahn — TCP/IP

Vint Cerf and Robert Kahn designed TCP/IP in the 1970s — the protocol suite that defines the internet.

  • Solved internetworking: how to connect many different, independent networks into one "network of networks."
  • IP handles addressing and routing; TCP ensures reliable, ordered delivery.
  • ARPANET switched to TCP/IP on January 1, 1983 — often cited as the internet's birthday.
  • Cerf and Kahn are frequently called the "fathers of the internet" and shared the 2004 Turing Award.
🔑 Why it matters:

TCP/IP's genius is that it makes no assumptions about the underlying networks. Any network that can move packets can join, which is why the internet could grow to encompass everything from fiber backbones to Wi-Fi to satellites.

Jon Postel — Steward of the Standards

Jon Postel (1943–1998) was the quiet steward who kept the early internet coherent.

  • Edited many foundational RFCs (the internet's specification documents) and administered the numbering/naming systems that became IANA and later DNS concepts.
  • Known for Postel's Law (the robustness principle): "Be conservative in what you send, be liberal in what you accept."

Tim Berners-Lee — The World Wide Web

Tim Berners-Lee, at CERN in 1989–1991, invented the World Wide Web — the layer that made the internet usable for everyone.

  • Created the three pillars still in use today: HTML (documents), HTTP (transfer protocol), and URLs (addresses).
  • Built the first web browser and web server.
  • Crucially, he and CERN released the web royalty-free (1993), ensuring it belonged to everyone.
  • Founded the W3C to steward open web standards. Received the 2016 Turing Award.
⚠️ Internet ≠ Web:

The internet is the underlying global network (TCP/IP, 1969–1983). The web is one application built on top of it (1989–1991). Email, FTP, and streaming are other applications that run on the same internet.

Key Questions

What is the difference between the internet and the World Wide Web?

The internet is the global network infrastructure that moves data between computers using TCP/IP. The web is one application layered on top of it, using HTTP, HTML, and URLs to link documents. You can use the internet without the web (email, video calls, file transfer) — the web is just its most famous use.

Why was packet switching such an important idea?

Traditional circuit switching dedicates a whole connection to one conversation, which is wasteful and fragile. Packet switching breaks data into packets routed independently, so many conversations share the same links and the network can route around failures. This made a resilient, scalable global network possible.

What made TCP/IP able to scale into the global internet?

TCP/IP is layered and network-agnostic. IP provides universal addressing and routing across heterogeneous networks; TCP adds reliability on top. Because it assumes nothing about the physical medium, any network that can carry packets can interconnect, allowing organic, decentralized growth.
