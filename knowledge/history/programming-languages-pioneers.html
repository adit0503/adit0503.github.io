Programming Languages & Their Pioneers

Hardware is inert without software. These are the people who invented the languages and disciplines that let humans express ideas to machines — from FORTRAN and Lisp to C, C++, and the science of algorithms.

John Backus — FORTRAN & BNF

John Backus (1924–2007) led the IBM team that created FORTRAN (1957), the first widely used high-level programming language.

  • FORTRAN (Formula Translation) let scientists write math-like code instead of assembly, and its optimizing compiler produced code fast enough to win skeptics over.
  • Backus later co-developed Backus–Naur Form (BNF), the standard notation for describing programming language grammar/syntax — still taught and used today.
  • Received the 1977 Turing Award.

John McCarthy — Lisp & AI

John McCarthy (1927–2011) created Lisp (1958), the second-oldest high-level language still in use.

  • Introduced ideas that shaped modern programming: recursion, garbage collection, conditionals, and treating code as data (homoiconicity).
  • Coined the term "Artificial Intelligence" in 1956 and founded the AI labs at MIT and Stanford.
  • Received the 1971 Turing Award.

Ritchie & Thompson — C and Unix

At Bell Labs, Dennis Ritchie (1941–2011) and Ken Thompson (b. 1943) built two of the most influential pieces of software ever written.

  • Thompson created the first Unix (1969); Ritchie created the C language (1972) and they rewrote Unix in C — making the OS portable across hardware.
  • C became the foundation for operating systems, embedded systems, and nearly every later language (C++, Java, C#, Go, Rust all trace lineage to it).
  • Unix shaped Linux, macOS, Android, and the philosophy of small composable tools.
  • Both shared the 1983 Turing Award.
🔑 Enduring impact:

The C/Unix combination is arguably the most consequential software project in history. Most of the digital infrastructure running today descends from it, directly or by influence.

Niklaus Wirth — Pascal & Simplicity

Niklaus Wirth (1934–2024), a Swiss computer scientist, designed Pascal (1970) and later Modula-2 and Oberon.

  • Pascal was designed for teaching structured programming and dominated computer science education for decades.
  • Championed clarity and minimalism — "Wirth's Law": software gets slower faster than hardware gets faster.
  • Received the 1984 Turing Award.

Object-Oriented Pioneers — Kay, Stroustrup, Liskov

  • Alan Kay — pioneered Smalltalk and coined "object-oriented programming," envisioning software built from communicating objects. Turing Award 2003.
  • Bjarne Stroustrup — created C++ (1979–1985), adding object orientation to C. It powers browsers, game engines, databases, and high-performance systems.
  • Barbara Liskov — pioneered data abstraction and the CLU language; the Liskov Substitution Principle (the "L" in SOLID) is named for her. Turing Award 2008.
  • Kristen Nygaard & Ole-Johan Dahl — created Simula (1960s), the first object-oriented language, introducing classes and objects. Turing Award 2001.

Dijkstra & Knuth — The Science of Programming

  • Edsger Dijkstra (1930–2002) — advocated structured programming ("Go To Statement Considered Harmful"), invented Dijkstra's shortest-path algorithm, and worked on concurrency (semaphores). Turing Award 1972.
  • Donald Knuth (b. 1938) — author of The Art of Computer Programming, formalized algorithm analysis (Big-O usage), and created the TeX typesetting system. Turing Award 1974.
⚠️ Software as engineering:

Dijkstra and Knuth pushed programming from ad-hoc craft toward a rigorous discipline with provable correctness and analyzable performance — the intellectual backbone of computer science.

Key Questions

Why was FORTRAN a turning point?

It was the first high-level language with a compiler good enough that programmers would trust it over hand-written assembly. It proved that abstraction need not sacrifice performance, opening the door to every high-level language that followed.

Why is C considered so influential?

C is low-level enough to write operating systems yet portable across hardware. Unix was rewritten in C, making it the first portable OS. C's syntax and semantics became the template for C++, Java, C#, JavaScript, Go, and more, so its influence is everywhere even in code that isn't C.

What is the Liskov Substitution Principle?

Objects of a subclass should be usable anywhere the parent class is expected without breaking correctness. Named after Barbara Liskov's work on data abstraction, it is the "L" in the SOLID design principles and a cornerstone of sound object-oriented design.
